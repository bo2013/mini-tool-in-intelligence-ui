# Obsidian

- **Design direction:** Minimal dark developer interface
- **Color palette:** Background `#101114`, surface `#1B1D22`, accent `#A3E635`, text `#F3F4F6`, muted `#9296A2`
- **Typography:** Inter, clean sans-serif; semibold headings, regular body text
- **Layout:** Compact, grid-based, clear visual hierarchy
- **Spacing:** 8px base scale; 16px card padding; 24px section spacing
- **Border radius:** 10px cards, 7px inputs, 7px buttons
- **Borders:** Subtle `#30323A` borders; avoid excessive shadows
- **Controls:** Lime accent for primary actions, focus rings, selected states
- **Density:** Compact but readable
- **Motion:** 120–180ms transitions, restrained hover feedback
- **Accessibility:** Maintain readable contrast and visible keyboard focus
- **Overall feel:** Technical, efficient, precise

# Swiss

- **Design direction:** Swiss modernism, editorial and functional
- **Color palette:** Background `#F7F7F4`, surface `#FFFFFF`, accent `#D92D20`, text `#171717`, muted `#666666`
- **Typography:** Helvetica Neue or Arial; strong typographic hierarchy
- **Layout:** Strict grid, aligned edges, generous whitespace
- **Spacing:** 8px base scale; 24px card padding; 32px section spacing
- **Border radius:** 2px throughout
- **Borders:** Thin neutral borders; no decorative shadows
- **Controls:** Solid red primary action, black secondary action
- **Density:** Comfortable
- **Motion:** Minimal, functional transitions only
- **Accessibility:** Strong text contrast and clear focus indicators
- **Overall feel:** Rational, editorial, timeless

# Soft Glass

- **Design direction:** Airy glassmorphism with restrained translucency
- **Color palette:** Background `#EEF1FA`, surface `rgba(255,255,255,0.72)`, accent `#6658D3`, text `#20233B`, muted `#70758F`
- **Typography:** Inter; medium-weight headings, regular body
- **Layout:** Spacious cards over a subtle cool gradient background
- **Spacing:** 8px base scale; 20px card padding; 28px section spacing
- **Border radius:** 18px cards, 12px inputs, 12px buttons
- **Borders:** Fine translucent white borders
- **Shadows:** Soft diffuse shadows, used sparingly
- **Controls:** Violet primary actions, gently tinted selected states
- **Density:** Comfortable
- **Motion:** 180–240ms easing, subtle elevation on hover
- **Accessibility:** Keep text surfaces sufficiently opaque for readability
- **Overall feel:** Light, modern, polished

# Neo Brutal

- **Design direction:** Neo-brutalist, bold and playful
- **Color palette:** Background `#FFF8E8`, surface `#FFFFFF`, accent `#FF5C35`, text `#171717`, muted `#5E574E`
- **Typography:** Arial or a bold grotesk; heavy headings
- **Layout:** Strong blocks, asymmetric accents, hard-edged surfaces
- **Spacing:** 8px base scale; 16px card padding; 24px section spacing
- **Border radius:** 0px throughout
- **Borders:** 2px solid `#171717`
- **Shadows:** Hard offset shadows, e.g. `4px 4px 0 #171717`
- **Controls:** Bright orange primary actions with black outlines
- **Density:** Compact
- **Motion:** Snappy, minimal movement; pressed states shift visibly
- **Accessibility:** Never rely on color alone for state
- **Overall feel:** Expressive, punchy, unconventional

# Midnight

- **Design direction:** Premium dark dashboard
- **Color palette:** Background `#0B1220`, surface `#131F32`, accent `#38BDF8`, text `#E5EDF8`, muted `#91A4BE`
- **Typography:** Inter; medium headings with tabular numerals for metrics
- **Layout:** Modular dashboard cards, consistent columns and spacing
- **Spacing:** 8px base scale; 20px card padding; 24px section spacing
- **Border radius:** 12px cards, 8px inputs and buttons
- **Borders:** Low-contrast blue-gray borders
- **Shadows:** Very subtle depth; no excessive glow
- **Controls:** Cyan primary actions, clear active navigation
- **Density:** Comfortable
- **Motion:** 160ms transitions, restrained chart animation
- **Accessibility:** Use cyan with adequate contrast and visible focus states
- **Overall feel:** Focused, technical, premium

# Warm Paper

- **Design direction:** Warm, tactile, paper-inspired interface
- **Color palette:** Background `#F4EFE6`, surface `#FFFCF6`, accent `#98613C`, text `#30271F`, muted `#827568`
- **Typography:** Georgia for prominent headings; Inter for controls and body
- **Layout:** Calm vertical rhythm, readable content widths
- **Spacing:** 8px base scale; 20px card padding; 28px section spacing
- **Border radius:** 8px cards, 6px inputs and buttons
- **Borders:** Warm beige borders
- **Shadows:** Minimal, warm-toned shadows if needed
- **Controls:** Brown primary actions, cream secondary surfaces
- **Density:** Comfortable
- **Motion:** Gentle 180ms transitions
- **Accessibility:** Avoid low-contrast beige text on cream surfaces
- **Overall feel:** Calm, approachable, thoughtful
